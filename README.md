# Echo
Сервис управления расписаниями и напоминаниями
<span style="color:#2E86C1; font-weight:bold">Современный инструмент для планирования событий, задач и напоминаний с веб-интерфейсом и Telegram-ботом.</span>

Amkaus - разработка телеграм-бота

style="color:#E74C3C">Функциональность:</span>

<span style="color:#27AE60">Веб-приложение</span>
 <span style="color:#2980B9">Аутентификация через JWT</span>

 <span style="color:#2980B9">CRUD для событий и календарей</span>

 <span style="color:#2980B9">Настройка цвета календарей</span>

 <span style="color:#2980B9">Просмотр расписания (день/неделя/месяц)</span>

<span style="color:#D35400">Telegram-бот</span>
 <span style="color:#8E44AD">Привязка аккаунта (/start)</span>

 <span style="color:#8E44AD">Просмотр событий дня (Today)</span>

 <span style="color:#8E44AD">Просмотр событий недели (Week)</span>

 <span style="color:#8E44AD">Список календарей (My Calendars)</span>

 <span style="color:#8E44AD">Справка (/help)</span>
 
 <span style="color:#8E44AD">Информация об аккаунте (My Account)</span>
