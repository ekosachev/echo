**_Telegram Echo Bot**_

В телеграм боте предоставлен ограниченный функционал:

1) Привязка аккаунта - безопасная аутентификация через логин и пароль от сайта Echo
2) Задачи на сегодня - просмотр всех задач на текущий день
3) Задачи на неделю - обзор всех задач на текущую неделю
4) Управление аккаунтом - информация о привязанном аккаунте


Чтобы начать пользоваться телеграм ботом, для начала нужно авторизоваться:

1) Запустите бота командой /start
2) Привяжите аккаунт - введите логин и пароль от сайта Echo

Доступные команды:

/start - начать работу и привязать аккаунт

/help - показать справку по командам

Today - показать задачи на сегодня

Week - показать задачи на неделю

My Account - информация о привязанном аккаунте


Формат отображения задач
Задачи отображаются с указанием:

1) Статуса выполнения (выполнено/не выполнено)

2) Приоритета (высокий, средний, низкий)

3) Времени выполнения (если указано)

4) Краткого описания
